# Machine Learning Project : Spaceship Titanic - Kaggle Competition

## 📝 Project Description
This project is my (multi) participation in the Kaggle competition ["Spaceship Titanic"](https://www.kaggle.com/competitions/spaceship-titanic). 

The story takes place in the year 2912. The interstellar spaceship *Spaceship Titanic* collided with a spacetime anomaly hidden within a dust cloud during its voyage to 55 Cancri E. The tragic consequence cause nearly half of the 13,000 passengers were transported to an alternate dimension. 

The goal of this project is to use Data Science skills to solve this cosmic mystery. It involves predicting which passengers were transported using a binary classification algorithm trained on data recovered from the spaceship's damaged computer system.

## 📁 Repository Structure
The project is professionally organized to clearly separate data, code, and final predictions:

* **`.vscode`**: Local development environment configuration.
* **`Data`**: Folder containing the raw data provided by Kaggle (`train.csv`, `test.csv`, `sample_submission.csv`).
* **`Notebooks`**: Jupyter Notebooks detailing the code evolution, from data cleaning to model training.
* **`Submissions`**: Prediction files in CSV format generated by the models and ready for Kaggle submission.

## 🛠️ Skills and Tools Used
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn (RandomForest, GradientBoosting, KNNImputer, GridSearchCV), XGBoost
* **Visualization:** Matplotlib, Seaborn

## 🧠 Approach and Feature Engineering
Special attention was given to data preparation to provide the algorithms with the most relevant signals:

* **Logical Deductions (Business Logic):** Filling missing values through intelligent cross-referencing. For example, a person in `CryoSleep` automatically incurs zero expenses, and vice versa.
* **Standardization and KNNImputer:** Using a `KNNImputer` on standardized data (Z-score) to accurately fill missing values in continuous variables (Age, Expenses).
* **New Variable Extraction (Feature Engineering):**
    * Splitting the Cabin identifier into 3 distinct variables: Deck (`Deck`), Number (`Num`), and Side (`Side`).
    * Analyzing the `PassengerId` variable to extract the travel group size (`GroupSize`), identify solo travelers (`IsAlone`), and deduce missing home planets for members of the same group.
* **Encoding:** Using One-Hot Encoding to transform textual categories (Planets, Destinations) into mathematically usable data.


## 🏆 Models and Results (Kaggle Score)
The project's development was divided into three phases, leading to the following results on the Kaggle Leaderboard (measured in Accuracy):

1. **`01_baseline_random_forest.ipynb`**
   * *Model:* Random Forest Classifier (Baseline to validate the cleaning approach)
   * *Score:* **79.261 %**
   
2. **`02_gradient_boosting_tuning.ipynb`**
   * *Model:* Gradient Boosting Classifier optimized via `GridSearchCV`
   * *Score:* **80.430 %** *(Current best score and Top 30% competition)*
   
3. **`03_xgboost.ipynb`**
   * *Model:* XGBoost Classifier optimized via `GridSearchCV` and advanced Feature Engineering on group size
   * *Score:* **80.216 %**

## 🚀 How to Run This Project Locally
1. Clone this repository to your machine.
2. Install the required dependencies (you can use `pip install pandas numpy scikit-learn xgboost matplotlib seaborn`).
3. Place the original Kaggle data files in the `Data` folder.
4. Open the files in the `Notebooks` folder using VS Code or Jupyter. The relative import paths will correctly read the data from `Data` and export your predictions to `Submissions`.
